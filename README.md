# AICloud-Assess

An intelligent framework for legacy software migration assessment in higher education using Machine Learning and Natural Language Processing.

## Overview
AICloud-Assess combines quantitative system metrics with qualitative documentation analysis to assess cloud migration feasibility for educational institutions.

## Features
- Hybrid ML + NLP approach
- Education-specific risk assessment
- Automated model selection (Random Forest, Gradient Boosting, XGBoost)
- Comprehensive resource estimation
- Synthetic dataset for research
